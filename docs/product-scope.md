# 当前产品范围：记忆优先

## 产品承诺

灵枢让同一台电脑上的多个 AI 工具共享用户控制的长期记忆。CLI 提供主要安装入口，个人客户端与网页控制台负责管理记忆、接入 MCP 和基础聊天；本地可用不要求登录云账户。

主要用户是同时使用 Claude、Cursor、Codex 等工具的个人开发者与 AI 重度用户。首要场景是把偏好、项目决定和经验从一个工具延续到另一个工具，不扩展为综合个人助理。

## 本轮保留与收敛

| 范围 | 当前处理 |
| --- | --- |
| 本地共享记忆 | 保留读写、搜索、编辑、删除，以及已有来源、权限、争议保留和人工裁决能力；治理通过现有 MCP / HTTP API 使用 |
| CLI 安装与管理 | 提供 start / stop / status / connect / open / mcp / update / uninstall；运行时自带 PostgreSQL 和网页控制台 |
| MCP 接入 | 核心入口；复用现有 6 个工具与接入配置，不要求付费或云登录 |
| 基础聊天 | 保留对话、历史、模型配置与记忆抽取；作为使用和积累记忆的辅助入口 |
| 个人客户端 | 导航收敛为记忆概览、记忆中心、接入 AI 工具、聊天、设置；云账户从右上角按需进入 |
| 隐私与同步 | 系统权限合并到设置；个人私有记忆加密云同步保留在云账户内，不自动开启 |
| 桌宠 | 取消桌面启动窗口；客户端构建不打包宠物页面，源码与开发页面暂保留 |
| 日历与项目任务 | 移出个人主流程；首页不请求相关数据，不扫描日历提醒 |
| 人格与思考队列 | 移除客户端入口，暂停新增产品需求；旧接口、数据和聊天后台处理暂保留兼容 |
| 团队 | 不进入个人客户端主流程；本地团队入口限开发版，既有云端团队网页、订阅、权限和数据继续兼容 |
| 实验台与离线评测 | 仅开发版使用，不作为普通用户的必经路径 |

收敛的是产品入口、默认启动行为和后续投入，不删除数据库、迁移、既有云订阅或兼容接口。现有聊天工具调用、人格提示与后台维护仍存在；需要另一次明确的后端收敛才能删除这些实现。本轮不新增独立的客户端冲突裁决页面。

## 不纳入当前迭代

- 桌宠陪伴、日程助理、项目任务管理、人格养成、主动思考与提醒。
- 新团队产品、企业版、OEM、SDK、SSO、组织知识接入。
- 远程跨设备 MCP 与商业高级治理：当前权益未开放，不能描述为已提供。
- 自动裁决事实冲突：仍以保留争议和人工裁决为准，未达到自动治理验收目标。

## 验收与后续投入

1. 未登录云账户也能进入记忆中心、使用本地 MCP 和聊天；基础聊天仍需可用模型。
2. 两个 AI 工具能通过现有 MCP 写入、读取同一套记忆；冲突不会静默变成确认事实。
3. 首页只展示记忆入口与最近记忆、对话；不请求日历、项目或任务，不启动提醒轮询。
4. 旧个人客户端入口回到记忆概览，客户端不能通过深链打开团队或实验台；开发兼容入口保留。
5. 桌面默认只创建主窗口；客户端产物无宠物页面。旧数据、云账户与订阅权益不迁移、不删除。

下一轮优先完善普通用户的来源追踪与冲突处理界面、接入成功检查、备份恢复和跨平台发布验证。新增功能必须改善记忆写入、找回、纠错或跨工具使用中的一个环节。
