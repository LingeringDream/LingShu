# 创新点说明

## 1. 三层可追溯认知协议

每轮完整交互先保存为 `episode`，结构化事实通过 `source_memory_ids` 回指原始片段，离线归纳的 `experience` 再回指多条事实。系统同时保留原始语境、可计算事实和可复用经验，避免传统 RAG 只保存摘要造成上下文丢失。

## 2. 数据库后置校验的 Memory Gateway

向量召回不能成为权限边界。灵枢把 Qdrant 定位为候选生成器，再由 PostgreSQL 基于用户、Agent、空间、定向授权和记忆状态做最终校验，阻止多 Agent 私有记忆因向量近似而越权泄露。

## 3. 有证据、可审计的时序冲突治理

事实更新不是简单“最后写入覆盖”。系统联合发生时间、来源可信度、交互频次与重要性计算双方证据，并输出 `challenger_wins`、`incumbent_wins` 或 `disputed`。每次裁决保留事实键、双方 ID、分差和原因。

## 4. 查询感知的自适应重排

普通查询采用语义、词法、时序、可信度、频次、重要性六维权重；检测到“现在、最新、目前”等时序意图时，动态提高新鲜度和可信度权重。过期、被替代与待争议事实在重排前过滤。

## 5. 评测即产品能力

静态基线和自适应模式使用同一入口、同一权限候选池，并将权重、结果 ID、耗时、过滤数和 Token 估算写入 `memory_retrieval_runs`。演示界面直接调用后端重跑 60 轮数据集与五组消融，指标不是写死的前端文案。
