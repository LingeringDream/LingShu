# 对比实验报告（自建回归集 v1）

日期：2026-09-02  
数据集：`LingShu-ZTE-50Turn-v1`  
规模：60 轮记忆、12 个时序/能力查询

## 实验设置

- 静态基线：词法/语义近似分数 + 固定重要性，不过滤被替代事实；上下文取 12 条。
- 完整模型：查询意图路由、六特征重排、冲突/过期过滤；上下文取 5 条。
- 消融：分别移除时间感知、来源可信度、交互频次、动态过滤。
- Token 为固定字符换算口径的上下文估算值，用于同数据、同实现的相对对比，不冒充模型供应商账单 Token。
- Top-K 指标在本数据集定义为 `Hit@5`，最终提交前需与企业确认其“Top-K 精准率”正式口径。

## 证据边界与下一轮实验

以上五项在**自建回归集与当前指标口径**下达到界面中列出的阈值，但不能直接声明已经满足企业最终验收：

1. 增加公开长记忆数据集并保留原始许可、转换脚本和版本哈希。
2. 将“复杂开放域任务完成度”从检索 Top-1 代理升级为端到端 Agent 任务判定。
3. 将 Hit@5 改为企业确认的 Top-K precision 公式并重新报告。
4. 至少重复运行 5 次，报告均值、标准差、P50/P95 时延。
5. 使用系统监控记录端侧峰值 RSS，与静态基线对比内存占用。
