# 中兴 1529 命题交付索引

正式命题：**面向智能体自主进化的动态记忆沉淀与自适应检索系统**  
原型名称：**灵枢 · Memory Evolution Lab**

本目录只记录可由当前代码复现的能力和证据，不把规划项写成已完成成绩。

## 已交付

- 完整源代码：Rust/Axum 后端、React/Tauri 演示端、PostgreSQL/Qdrant 存储。
- 三层记忆协议：`episode` 原始交互片段、`fact` 结构化事实、`experience` 通用经验。
- 多 Agent Memory Gateway：私有、定向共享、全局公共空间及按记忆授权。
- 时序冲突治理：事实键、有效时间、来源可信度、访问频次、重要性联合裁决，保留冲突事件。
- 自适应检索：语义、词法、时序、可信度、频次、重要性重排，过期与被替代记忆自动过滤。
- 静态 RAG 基线：同一 API 可切换 `static` / `adaptive`，每次运行保存耗时、Token 估算、过滤数、权重与结果 ID。
- 标准化自建数据集：[`datasets/zte_memory_50turn_v1.json`](../../datasets/zte_memory_50turn_v1.json)，含 60 轮记忆及 12 个时序查询。
- 自动评测与消融：完整模型、移除时间、移除可信度、移除频次、移除动态过滤。
- 可视化演示：侧栏“记忆进化实验台”。
