## 已交付

本节指仓库源码实现，不代表这些改动已进入已发布安装包或已部署到用户设备。

- 2026-09-08 在线链路改进：共享词法/向量召回、事务抽取、持久化索引、有效时间查询、有界合并与派生失效传播；见[实现与回归说明](../memory-retrieval-optimization.md)。新增 7 查询合成回归不替代下述正式质量评测。

- 完整源代码：Rust/Axum 后端、React/Tauri 演示端、PostgreSQL/Qdrant 存储。
- 三层记忆协议：`episode` 原始交互片段、`fact` 结构化事实、`experience` 通用经验。
- 多 Agent Memory Gateway：私有、定向共享、全局公共空间及按记忆授权。
- 时序冲突治理：按事实作用域、权限与有效时间识别冲突，事实级事务锁协调并发写入；不同主张保留为争议，人工裁决后标记被替代项并保留来源，见[并发写入协议](../memory-write-consistency.md)。
- 自适应检索：语义、词法、时序、可信度、频次、重要性重排，过期与被替代记忆自动过滤。
- 静态 RAG 基线：同一 API 可切换 `static` / `adaptive`，每次运行保存耗时、Token 估算、过滤数、权重与结果 ID。
- 自建数据集：保留 v1/v2，新增 [v3 合成集](../../datasets/zte_memory_v3_all.json)（660 轮、300 查询，按项目拆分 200 dev / 100 test）；状态为 oracle 标签，不是自动治理结果。
- 公开集实验：LoCoMo 1,977 个有证据 QA，包含向量、BM25、RRF、抽取式事实候选与同预算本地问答对照；新增检索策略尚未接入生产。
- 自动评测与消融：独立 `lingshu-eval` 复用生产排序代码，输出标准 P@K、R@K、Top-1 等指标，包含完整策略、特征消融和相似度＋状态过滤对照。
- 可视化演示：开发版 / 竞赛版提供 Memory Console、Agent Governance、Benchmark & Integration；个人桌面构建不提供实验台入口。
