# 相关工作（Related Work）

本文只讨论已经影响灵枢功能设计的研究工作。论文中的实验结果属于原作者自报数据，不作为灵枢自身性能结论；灵枢采用独立实现，不直接集成这些研究原型的代码。

## 1. 分层长期记忆与经验演化

[MemGPT](https://arxiv.org/abs/2310.08560) 将有限上下文下的长期交互建模为类似操作系统虚拟内存的分层管理问题，通过不同记忆层之间的数据移动扩展模型可用上下文。灵枢沿用“不同信息应进入不同持久层”的思想，但采用面向可审计业务数据的 `episode`、`fact`、`experience` 三层协议：原始交互保留语境，事实层提供可计算的事实键与有效期，经验层保存从多条来源归纳出的复用知识；每条派生记忆通过 `source_memory_ids` 回指证据。

[A-MEM](https://arxiv.org/abs/2502.12110) 借鉴卡片盒方法，为新记忆生成结构化属性、建立相关连接，并允许新证据更新既有记忆的上下文表示。灵枢当前实现了带场景标签的记忆写入、来源链和离线经验合并，但没有照搬其知识网络结构，也尚未实现通用的历史记忆反向改写。为避免不可审计的隐式更新，灵枢现阶段只在明确的冲突裁决后生成新的经验记录，保留旧事实及完整裁决链。

[WikiSkill](https://arxiv.org/abs/2608.27454) 将原始执行经验、持续积累的知识与可执行技能分离，并强调后续技能更新应复用持久知识。灵枢当前对应前两层：事实冲突经人工确认后，裁决结果会被编译成带双向来源证据的 `experience`，使“采用了什么、拒绝了什么、依据是什么”可以被后续检索使用。可执行技能版本化与规则回滚仍属于后续功能，本文不将其表述为已完成能力。

## 2. 多 Agent 记忆共享与访问边界

[Collaborative Memory](https://arxiv.org/abs/2505.18279) 面向多用户、多 Agent 场景提出私有与共享记忆层，并通过动态、非对称访问策略和不可变来源信息支持回溯检查。灵枢将这一问题落实为 Memory Gateway：记忆具有所有者与 `private`、`shared`、`global` 空间，定向共享由逐记忆授权表记录。

灵枢不把向量数据库当作权限边界。Qdrant 只提供语义候选，最终候选必须由 PostgreSQL 按用户、所有者、空间和授权记录校验；ACL 条件在数据库分页之前执行，避免无权记录占满候选窗口。冲突治理也限定在同一记忆所有者域内，防止不同 Agent 的私有事实因相同事实键而互相覆盖。当前 Agent 是同一用户工作区内的逻辑身份，不等同于独立用户认证主体。

## 3. 选择性遗忘与冲突治理

[MemoryBank](https://arxiv.org/abs/2305.10250) 使用受遗忘曲线启发的更新机制，根据时间和记忆重要性选择性保留或强化信息。灵枢采用指数半衰期衰减，并增加两类保护：高重要度记忆不会因时间自动遗忘，被人格快照或派生经验引用的来源记忆也不会被清理，以保持证据链完整。

[FadeMem](https://arxiv.org/abs/2601.18642) 将自适应指数衰减、访问频次、时间模式、冲突消解和记忆融合组合为主动遗忘架构。灵枢采用相近的问题拆分，但使用确定性的可解释策略：事实更新联合来源可信度、发生时间、访问频次和重要性计算证据分数；明显占优的一方自动生效，分差落入阈值的双方进入 `disputed` 状态。

对于 `disputed` 事实，Memory Gateway 提供人工裁决接口。裁决会原子地恢复获胜事实、过滤落败事实、更新冲突账本，并可生成 `source_type=conflict_resolution` 的经验记忆。该经验继承记忆所有者，但权限取两个来源的保守交集：混合空间降为私有，两侧均为定向共享时只保留共有授权。来源同时指向两个候选，因此后续系统既能复用结论，也能追溯被否决证据。

## 4. 与现有工作的区别

灵枢的主要差异不在于引入一种新的向量检索算法，而在于把长期记忆组织成可执行的治理协议：

- 分层记忆不是三个独立摘要池，而是可沿来源 ID 回溯的证据链。
- 向量召回不承担权限判断，访问结果必须经过关系数据库的确定性校验。
- 冲突事实不使用简单的最后写入覆盖；自动裁决不确定时进入人工复核。
- 被否决的候选不会直接消失，裁决可转化为带正反证据的复用经验。
- 遗忘操作受重要性和来源链保护，避免派生结论仍在而原始证据已经丢失。

上述设计目前覆盖记忆沉淀、共享、冲突、人工裁决和选择性遗忘。通用记忆关系分类、历史经验的自动反向更新、技能编译与版本回滚尚未完成，后续实现时应继续保留显式来源、权限继承和可撤销性约束。
