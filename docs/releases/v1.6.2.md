# 灵枢 LingShu v1.6.2

个人客户端聚焦共享记忆、记忆管理和基础聊天。新增命令行安装入口：一个发行包包含后台服务、PostgreSQL、MCP 和网页控制台，无需 Rust、Node 或 Docker。

## 在线安装

当前仓库为私有仓库。先安装 GitHub CLI，执行 `gh auth login`，并确认账户有 `LingeringDream/LingShu` 访问权限。

macOS（Apple Silicon / Intel）和 Linux x64：

```sh
gh release download v1.6.2 --repo LingeringDream/LingShu --pattern install.sh --dir /tmp --clobber
sh /tmp/install.sh --version v1.6.2
~/.local/bin/lingshu start
~/.local/bin/lingshu connect cursor
~/.local/bin/lingshu open
```

Windows x64（PowerShell）：

```powershell
gh release download v1.6.2 --repo LingeringDream/LingShu --pattern install.ps1 --dir "$env:TEMP" --clobber
& "$env:TEMP\install.ps1" --version v1.6.2
```

打开新终端后运行 `lingshu start`、`lingshu connect cursor`、`lingshu open`。也支持 `connect claude` 和 `connect codex`。

## 升级和数据

- 安装器验证 SHA-256、目标平台和程序版本后切换程序；Linux 额外验证所需 glibc 版本。
- `lingshu update` 保留记忆、配置和密钥；原先运行的服务自动恢复。
- `lingshu uninstall` 默认保留数据；只有明确指定 `--purge` 才删除 CLI 数据。
- CLI 使用独立数据目录，不自动迁移已有桌面客户端数据。
- 默认 HTTP 端口 8080、数据库端口 55433；服务不注册开机启动。
- 基础聊天需配置模型服务；没有模型也可使用本地记忆和 MCP。

四个平台的 CLI 包通过安装、实际记忆读写、MCP、升级、卸载和显式清除数据的检查后发布。桌面安装包单独上传。

详细说明见仓库内的 [命令行安装文档](https://github.com/LingeringDream/LingShu/blob/v1.6.2/docs/cli-installation.md)。
