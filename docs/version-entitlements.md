# 个人版软件权益实施说明

当前软件仅包含免费版 Free、专业版 Pro、团队版 Team 三档。企业版与嵌入/OEM 属于独立产品，不使用当前软件，不出现在当前软件的权益列表和升级入口中。

版本权益由云端 `lingshu-cloud/src/entitlements.ts` 统一计算，账户订阅接口返回 `entitlements.effective_plan` 和功能列表。每项功能分别提供版本是否包含（included）、是否已开放（available）、当前能否使用（enabled）。客户端只展示结果，受限操作仍由后端读取可信订阅校验。

| 版本 | 当前能力 | 未开放的目标权益 |
| --- | --- | --- |
| Free | 本地聊天、动态记忆、本地 MCP、备份 | — |
| Pro | Free 全部能力、端到端加密云同步、多设备连续记忆与本机 MCP、同步冲突历史、高级记忆治理、检索权重自定义 | — |
| Team | Pro 全部能力、创建团队工作区 | 按席位账单、团队 MCP |

兼容已有 Pro 订阅代码 `developer`，权益计算统一为 `pro`；账单和 Stripe 历史数据不迁移。企业版与嵌入版订阅代码不授予本软件的付费权益；本软件不提供其购买入口。

有效订阅状态为 active、trialing，以及尚在有效期内的 past_due。有明确到期时间时，到期即失效，即使数据库状态仍为 active；无效日期、未知版本、已取消订阅不授予付费权益。active / trialing 的空到期时间继续兼容已有订阅数据。失效订阅按 Free 计算，本地数据与本地 MCP 不受影响。

创建团队：云端 API、网页团队入口和 Rust 团队服务器支持有效 Team。网页入口也允许已有团队成员进入；免费账号可接受邀请，团队内操作继续按已有角色和记忆访问授权执行。本次按订阅限制创建工作区，不因创建者降级自动冻结既有团队或删除数据。

客户端「云账户」展示生效版本及可用、需升级、尚未开放状态。「团队工作区」在权益未获取或版本不足时禁用创建按钮，保留加入团队。旧云服务未返回权益时，需要升级服务并刷新账户信息。界面缓存仅用于提示，后端始终重新校验创建请求。

Pro 同步采用客户端 AES-256-GCM 加密。云端只保存密文快照、修订元数据和最近 50 次历史；同步加密口令不上传、不写入普通本地存储，遗失后云端无法恢复。多设备以记忆 `updated_at` 做确定性的末次写入优先合并，删除以 tombstone 同步；修订号冲突会重新拉取、合并并重试。同步保留三层记忆、来源、作用域、冲突与留存状态，并同步用户自定义的检索权重。跨设备 MCP 通过“每台设备先同步到本地、再由免费本机 MCP 访问”实现，不开放持有明文的云端 MCP。
