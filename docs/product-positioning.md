# 灵枢产品定位

## 当前定位

灵枢是连接常用 AI 工具的个人共享记忆层。用户在本机管理自己的长期记忆，通过 MCP 让 Claude、Cursor、Codex 等工具延续偏好、项目决定与经验。

核心目标：一处管理记忆，多工具持续使用，发生冲突时保留证据并由人裁决。

目标用户是同时使用多个 AI 工具的个人开发者与 AI 重度用户。个人客户端以记忆为主，保留基础聊天；桌宠、日程、任务、人格和思考队列退出主流程。完整边界及验收条件见[当前产品范围](product-scope.md)。

## 核心使用方式

| 入口 | 用途 |
| --- | --- |
| CLI 安装 | 安装并管理本地记忆服务，按需打开网页控制台；源码已实现，发行包待发布 |
| MCP | 常用 AI 工具读取、写入、共享记忆；本地核心入口 |
| 记忆客户端 | 搜索、添加、修正、删除记忆，配置 MCP 与模型；基础聊天积累上下文 |
| HTTP API | 支撑已有客户端、MCP 和集成，保持兼容；不扩展为新企业产品承诺 |

例如，Cursor 写入“这个项目使用 PostgreSQL”，Claude 随后读取该决定；Codex 写入相反主张时，系统保留争议，经过人工裁决后再提供确认事实。

MCP、聊天和本地 Gateway 共用记忆检索与治理内核。云端团队服务是既有兼容产品，不能据此宣称它与本地 Gateway 完全等价。

## 免费与付费边界

| 版本 | 当前可用 | 产品范围 |
| --- | --- | --- |
| Free | 本地记忆、本地 MCP、基础聊天及已有备份能力 | 当前核心；模型使用本地 Ollama 或自备 API Key |
| Pro | Free 本地能力、个人私有记忆端到端加密云同步 | 可选升级；同步需用户配置和执行 |
| Team | 既有团队创建、成员与共享记忆权限能力；有效权益以服务端返回为准 | 兼容既有账户和团队网页，不扩展个人客户端主流程 |

跨设备远程 MCP、高级商业治理、团队 MCP 与按席位账单尚未开放。Enterprise、Embedded / OEM、Python / TypeScript SDK 不纳入当前迭代。订阅与功能校验以[版本权益实施说明](version-entitlements.md)和云端代码为准，本轮不改变套餐或账单。

云端仅保存同步密文，不持有恢复密钥。个人私有记忆同步不等于团队记忆共享，也不等于远程 MCP 已上线。

## 产品决策原则

1. 本地记忆和本地 MCP 不依赖云登录，也不设置付费门槛。
2. 优先改善跨工具接入、记忆找回、来源追踪、冲突处理与备份恢复。
3. 聊天是辅助入口，不以通用助理能力竞争。
4. 不把保留的历史模块、研究实验或规划权益描述为当前产品主线。
5. AI 写入可以被质疑；争议保留来源，自动事实治理未达标时继续人工裁决。
6. 发布能力以实际安装包与验证记录为准，源码实现不等于已部署。

记忆工程实现与实验边界继续参考[检索改进说明](memory-retrieval-optimization.md)和[自动治理审计](research/auto-governance-audit.md)。
