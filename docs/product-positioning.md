# 灵枢产品定位与版本体系

## 核心定位

灵枢是连接不同 AI 工具的个人、团队与企业记忆层。它既提供自己的桌面客户端，也允许用户继续使用 Claude、Cursor、Codex 等现有工具，并通过 MCP 共享同一套记忆、项目上下文、偏好、决策和经验。

> **灵枢不是另一个 AI。灵枢是连接所有 AI 的记忆层。**

产品围绕一个核心目标展开：让用户拥有独立于单一模型和单一应用的长期记忆，并能决定这些记忆由谁读取、由谁写入、如何同步以及如何治理。

## 三种使用方式

| 使用方式 | 用户行为 | 典型场景 |
|---|---|---|
| **灵枢客户端** | 直接使用灵枢提供的 AI 助手和记忆管理界面 | 聊天、记忆管理、日历、人格、思考队列 |
| **MCP 接入** | 保留原有 AI 工具，为其接入灵枢记忆 | Claude、Cursor、Codex 等读取或写入同一套用户记忆 |
| **HTTP API** | 通过已有服务端接口将上下文与记忆能力嵌入第三方产品 | AI 客服、AI CRM、Agent 平台、垂直 AI 应用 |

MCP 是 C 端的核心入口之一。用户不需要每天打开灵枢客户端，也能在日常使用的 AI 工具中持续调用灵枢记忆。

```text
Claude   Cursor   Codex   其他 MCP AI
   \       |       |       /
                 MCP
                  |
                  v
            灵枢用户记忆层
      记忆 · 项目 · 偏好 · 决策 · 经验
```

例如，Cursor 写入“这个项目统一使用 PostgreSQL”，Claude 随后可以读取这项决定；Codex 完成支付模块迁移后，又可将新的项目状态写回灵枢。不同 AI 围绕同一个由用户控制的记忆层工作。

## 产品版本

当前个人版软件仅承载 Free、Pro、Team 三档权益。下表中的 Enterprise、Embedded / OEM 是独立产品规划，不通过当前软件提供，也不纳入当前软件的版本升级链。

| 市场 | 版本 | 面向用户 | 核心能力 |
|---|---|---|---|
| C 端 | **免费版 Free** | 单机个人用户、体验用户 | 本地聊天、本地动态记忆、本地模型或自备 API Key、基础记忆检索、本地备份；提供本地 MCP Server，让同一台电脑上支持 MCP 的 AI 工具读取和写入本机灵枢记忆 |
| C 端 | **专业版 Pro** | AI 重度用户、开发者、研究者、多设备用户 | Free 全部能力；加密云同步、多设备连续记忆、冲突历史、高级记忆治理、高级经验沉淀、记忆参数自定义；支持跨设备 MCP 接入，让多台设备上的多个 AI 工具共享同一用户记忆 |
| C 端 | **团队版 Team** | 小团队、实验室、工作室 | Pro 全部能力；团队工作区、项目共享记忆、成员权限、团队审计、统一账单；提供团队 MCP 空间，不同成员和不同 AI 按权限访问共享记忆 |
| B 端 | **企业版 Enterprise** | 内部大量使用 AI 或 Agent 的企业 | 企业统一上下文中心、部门与项目隔离、Agent 身份、RBAC、审计、来源追踪、冲突治理、企业知识接入、SSO、数据治理；提供 Enterprise MCP Gateway，并支持云、VPC 和私有部署 |
| B 端 | **嵌入版 Embedded / OEM** | AI SaaS、Agent 平台、AI 软件公司 | Context / Memory API、Python / TypeScript SDK、MCP Server、多租户、长期记忆、冲突治理、检索、权限、白标、OEM 和私有部署 |

以上是目标产品体系，不等于当前已上线清单。当前已实现客户端、MCP 和 HTTP API；Python / TypeScript SDK、加密云同步、跨设备 MCP、团队 MCP 与按席位账单尚未开放。有效 Team 订阅已可创建团队工作区，受邀 Free 用户可加入。具体边界以[版本权益实施说明](version-entitlements.md)、README、更新日志和正式发布说明为准。

## 各版本的一句话说明

- **Free：让一台电脑上的所有 AI 认识你。**
- **Pro：让你所有设备上的所有 AI 都认识你。**
- **Team：让一个团队和他们使用的所有 AI 共享项目记忆。**
- **Enterprise：让一家公司的所有 AI 在权限范围内共享企业上下文。**
- **Embedded：让第三方 AI 产品直接拥有灵枢的记忆能力。**

## 免费与付费边界

本地 MCP 属于免费版本地核心能力，不作为单独付费门槛。它承担产品体验与获客作用：用户安装灵枢后，即可让同一台电脑上的多个 AI 工具共享记忆。

Pro 的目标付费价值是跨设备连续性。计划中，用户为加密云同步、多设备冲突处理和高级记忆治理付费，使不同电脑上的 AI 工具能够连接到同一个持续更新的用户记忆层；这些能力当前尚未开放。

```text
Free

一台设备：Claude / Cursor / Codex
                  |
                  v
              本地灵枢记忆

Pro

Mac 上的 AI ---------\
                      > 加密云同步 -> 同一个用户记忆层
Windows 上的 AI -----/
```

Team、Enterprise 和 Embedded 的付费价值依次扩展到协作权限、组织治理和第三方产品集成。版本升级围绕记忆的覆盖范围、治理深度和部署方式展开，而不是限制用户在本机通过 MCP 使用自己的记忆。

## 产品决策原则

1. 用户记忆独立于单一模型、AI 工具和设备。
2. 本地优先，Free 提供可用的本地记忆与本地 MCP 能力。
3. 云同步是 Pro 的主要升级理由，权限协作是 Team 的主要升级理由。
4. 已有 MCP 和 HTTP API 共享同一套身份、权限、审计、来源追踪与冲突治理规则；后续 SDK 沿用该规则。
5. AI 写入不会自动成为不可质疑的事实；冲突主张保留来源并接受用户或组织规则裁决。
6. 产品页面必须区分当前已上线能力和规划能力，避免把路线图描述为现状。
