    01

    安装与首次启动

    灵枢桌面端采用本地优先模式。安装完成后无需注册云账户，也可以创建本地会话并使用本地核心功能。Windows 安装包已内置 PostgreSQL 数据库与运行库，无需单独安装数据库。

    1. 选择安装包。Windows 10/11 x64 使用 .exe；Apple Silicon Mac 使用 macOS 14+ 的 .dmg。
    2. 完成文件校验。下载后先核对下载中心公布的文件名和 SHA-256，再运行安装程序。
    3. 启动灵枢。首次启动会初始化内置数据库并创建本地会话。数据库初始化需要 1–2 分钟，期间界面保持等待属正常现象，请勿强制结束进程。
    4. 按需登录云账户。只有需要账户、设备、Pro 跨设备同步或团队工作区时，才需要登录云账户。
    • 重复打开只会聚焦已有窗口：灵枢为单实例应用，再次启动会显示并聚焦已打开的控制面板，不会产生第二个实例。
    • 关闭主窗口不等于退出：点击主窗口关闭按钮只是隐藏窗口，灵枢与桌面宠物会继续在托盘运行；从托盘图标选择“退出”才会完全退出。
    • macOS 首次打开：若提示无法验证开发者，请在“系统设置 → 隐私与安全性”中允许，或右键应用选择“打开”。

    数据边界：网页云账户和桌面端本地会话彼此独立。退出云账户不会删除桌面端本地数据。

    02

    注册与邮箱验证

    未验证的注册记录不会成为正式账户。验证链接为一次性链接，默认在发送后 24 小时失效。

    1. 退出当前账户，在登录页选择“注册账户”。
    2. 填写显示名称、可接收邮件的邮箱，以及 12–128 个字符的密码。
    3. 提交后打开主题为 LingShu 账户验证的邮件，点击其中的验证链接。
    4. 页面显示“邮箱验证成功”后返回登录，使用注册邮箱和密码登录。
    没有收到邮件？

    先检查垃圾邮件、推广邮件和邮箱地址。仍在有效期内的待验证注册不会重复发送第二封邮件；超过 24 小时后可重新提交注册以生成新链接。

    03

    登录、续期与退出

    通过网页登录软件：在软件“云账户”页点击“通过网页登录”。本浏览器已有登录状态时会自动验证；未登录时先在此登录，成功后软件自动登录同一账号。无需复制验证码。若等待超过 5 分钟或已关闭软件，请从软件重新发起。旧版已打开的账户网页刷新一次即可迁移登录状态。

    在带有“云账户”入口的软件版本中，点击侧栏“云账户”或右上角“登录云账户”，输入与本站相同的邮箱、密码和设备名称。登录后可以查看订阅，并从软件打开网页账户中心。网页与软件分别保持登录会话；软件会安全保存登录状态，重启后自动恢复。若安装的软件尚无此入口，请等待包含此功能的更新版本。

    每次在新浏览器或新设备登录都会创建独立设备会话。短期访问凭证默认有效 15 分钟，页面会使用可轮换的设备凭证自动续期，最长有效期默认 30 天。

    • 登录失败限制：15 分钟内连续失败 5 次后，会按 IP、邮箱和设备暂时限制约 15 分钟。
    • 设备复用：同一浏览器首次登录会创建设备记录，之后的登录会复用该记录，不会重复创建设备。
    • 正常退出：点击右上角“退出登录”，当前浏览器保存的云会话会被注销。
    • 软件退出：在软件“云账户”页点击“退出云账户”。退出需要联网撤销本机云会话；断网时会提示重试，本地聊天和记忆仍可使用。
    • 会话失效：长时间未使用、设备被撤销或检测到旧刷新凭证重复使用时，需要重新登录。
    • 本地影响：云会话失效只影响账户网页与云服务，不会使桌面端本地会话失效。
    04

    设备管理与远程撤销

    “设备与会话”页面会显示当前设备和其他已登录设备，并记录设备名称、平台及最近活动时间。设备名称按浏览器与系统自动生成，例如“Windows 浏览器”“Mac 浏览器”。

    1. 打开“设备与会话”，先确认标有“当前设备”的条目。
    2. 发现不认识、遗失或不再使用的设备时，点击该设备旁的“撤销”。
    3. 确认后，该设备下的全部云会话立即失效；设备再次访问云账户时必须重新登录。

    出现多台同类设备？首次登录或清理浏览器站点数据后，灵枢无法识别原有设备，会新建一条设备记录。同一浏览器之后的登录会复用设备，不会再增加记录；多余的旧记录可直接撤销。

    安全建议：若怀疑密码泄露，请先撤销可疑设备。当前版本尚未提供网页修改密码，请不要在多个服务重复使用同一密码。

    05

    本地功能与模型接入

    灵枢的本地核心能力不依赖云账户，也不设付费墙。安装后即可创建本地会话，自由接入本地模型或自备 API Key，配置保存在本机，重启后保留。

    • 本地会话：不登录云账户也能完整使用对话、记忆、人格、日历与项目管理等本地功能。
    • 多模型接入：支持 Ollama 本地模型（默认）或任意 OpenAI 兼容端点（如 DeepSeek）。在聊天设置中选择模型、最大 Token 与上下文轮数，修改后自动保存。
    • 嵌入模型：语义记忆检索需要 Ollama 嵌入模型 nomic-embed-text（ollama pull nomic-embed-text）；未配置时记忆检索自动回退为 SQL 匹配。
    • 联网搜索：对话内可搜索公开网页并返回标题、摘要与来源链接。该能力由独立权限开关控制，默认关闭。
    • 角色提示词：可自定义系统角色提示词，集成进对话工作区；消息支持 Markdown 渲染。

    费用口径：本地模型与自备 API Key 不产生订阅费用；官方托管模型按量计费，与订阅费分开结算。

    06

    记忆、人格与系统能力

    灵枢内置长期记忆（SoulLedger）、可控人格与主动建议（Thought Queue），并对系统权限实行分级管理，全部默认保存在本地。

    • 分层记忆（SoulLedger）：记忆分为原始片段、结构化事实与通用经验三层，支持去重、遗忘衰减、语义检索与来源追溯。
    • 人格演化：人格特征随对话持续演化，可在人格中心查看与调整。
    • 主动建议（Thought Queue）：基于状态机生成带可解释置信度的建议，并具备防打扰抑制，不会频繁打断。
    • 权限分级 L0–L4：默认权限为 L0。日历、联网搜索等敏感能力需要先开启 L1 权限；所有权限操作都会写入审计日志。
    • 日历：macOS 14+ 可通过系统日历（EventKit）创建、修改与删除事件，需在系统设置中授予日历权限；Windows 与网页版通过导出 .ics 日历文件完成交付。
    • 平台能力边界：屏幕读取、应用自动化等为 macOS 原生能力；Windows 与网页版会自动隐藏或降级不可用的入口，不会出现误导性按钮。

    安全：集成令牌使用 AES-256-GCM 静态加密；本机服务默认只绑定 127.0.0.1，不对外网开放。

    07

    记忆同步：Pro 已开放

    有效的 Pro 或 Team 权益可在桌面端进行端到端加密的双向记忆同步。加密和解密只在设备本地完成；云端保存 AES-256-GCM 密文快照、修订元数据和最近 50 次同步历史，无法读取记忆正文。

    1. 登录桌面端云账户。打开“云账户”，确认当前权益中“端到端加密云同步”显示为“可用”。
    2. 输入同步加密口令。口令至少 12 个字符；同一账户的所有设备必须使用完全相同的口令。
    3. 首次手动同步。点击“立即双向同步”。灵枢会先在本机解密云端快照，以记忆修改时间合并两端数据，再上传新的密文修订。
    4. 按需开启自动同步。开启后，完成一次解锁的本次运行会每 5 分钟同步，并在恢复联网时重试。
    5. 在其他设备重复操作。登录同一账户并输入相同口令后执行双向同步；合并完成后，该设备的本机 MCP 会直接使用最新本地记忆。
    • 登录不会直接上传：必须输入同步加密口令并手动同步一次，才会开始本次运行的同步。
    • 口令不会持久保存：口令只在软件本次运行期间保存在内存中，重启后需重新输入；云端无法读取、找回或重置它。
    • 删除也会同步：删除记录以 tombstone 合并，避免旧设备把已删除记忆重新带回。
    • 并发冲突会自动重试：若多台设备同时写入，客户端会重新拉取并合并；连续冲突时请稍后再次点击同步。
    • 断网不影响本地：本地会话、记忆与本机 MCP 可继续使用，联网后再同步。

    请先备份口令和本地数据：遗失同步口令后无法解密已有云端快照。云同步用于多设备连续使用，不替代你自己的灾难恢复备份。

    本地数据位置（Windows）：桌面端数据保存在 %APPDATA%\com.lingshu.desktop\embedded-postgresql 目录。重装系统、更换电脑前，请备份整个 com.lingshu.desktop 目录；恢复时放回相同位置即可。

    付款安全：支付由微信支付 / 支付宝处理，LingShu 仅保存订单号、支付状态与权益周期，不保存支付密码或完整卡号。

    团队工作区

    团队工作区目前面向已有有效 Team 测试权益的账户开放创建。受邀成员即使个人账户为 Free 或 Pro，也可以接受邀请并进入已有工作区。

    1. 创建工作区：拥有有效 Team 权益的账户登录后打开“团队工作区”，填写名称并创建；受邀成员不能凭成员身份再创建新工作区。
    2. 邀请成员：所有者或管理员使用成员邮箱发送邀请；对方注册并验证同一邮箱后即可接受。
    3. 分配角色：所有者、管理员、编辑者和只读成员拥有不同的成员管理与记忆写入权限。
    4. 管理共享记忆：记忆可设为私有、定向共享或团队全局；只读成员只能查看有权访问的内容。
    5. 查看治理记录：管理员可查看最近的团队审计事件，并管理团队访问密钥。

    当前边界：团队 MCP 空间和按席位统一账单尚未开放；当前团队工作区不等同于企业私有部署，也不会自动读取个人本地记忆。

    开发版与竞赛演示

    灵枢提供面向演示与竞赛的 Windows 开发版：基于 Docker 一键启动完整的“动态记忆引擎”控制台，无需手动安装数据库、向量库或编译环境。

    1. 准备环境：安装 Docker Desktop 并完成 WSL 2 初始化，预留至少 8 GB 可用磁盘空间；首次构建需要联网下载基础镜像。
    2. 解压开发包：将整个开发包解压到本地目录，不要只打开 ZIP 内的文件。
    3. 一键启动：双击根目录 启动灵枢竞赛版.cmd，等待所有检查显示 [OK]，浏览器会自动打开 Memory Console；若未自动打开，双击 打开灵枢控制台.cmd 或访问 http://127.0.0.1:5173/?section=memory-lab。
    4. 停止服务：双击 停止灵枢开发版.cmd。停止操作只关闭容器，会保留 PostgreSQL、Redis 和 Qdrant 数据卷与已有记忆数据。
    • Ollama 为可选：未安装 Ollama 时启动器显示 [WARN]，记忆控制台与演示数据仍可使用；本地聊天和向量嵌入需要启动 Ollama，或在设置中配置兼容的模型 API。
    • 常用地址：Memory Console http://127.0.0.1:5173/?section=memory-lab · Swagger API http://127.0.0.1:8080/swagger-ui · Qdrant http://127.0.0.1:6333/dashboard。
    • 首次构建较慢：首次构建 Rust 后端需要数分钟，后续启动会复用 Docker 缓存。

    故障排查：启动器会检查项目文件、Docker CLI、Docker Compose、Docker Engine、端口占用和服务健康状态。失败时按窗口中的 Missing or unavailable 与 How to fix 提示处理；后端或前端启动失败时，窗口底部会显示容器状态与最近日志。

    常见问题

    首次启动很久没有反应
    首次启动需要初始化内置数据库，等待 1–2 分钟属正常现象，请勿强制结束进程。超过 5 分钟仍无窗口时，关闭后重新打开应用。
    提示本地服务启动失败 / 无法连接本地服务
    桌面端启动时会拉起本地后端服务，若被安全软件拦截、端口被占用或安装文件不完整会提示失败。先重启应用；仍失败时查看应用数据目录下的 sidecar.log 日志内容（Windows 位于 %APPDATA%\com.lingshu.desktop\sidecar.log），并据此反馈或排查。
    重复打开安装程序后出现多个窗口
    灵枢为单实例应用：再次启动会显示并聚焦已打开的控制面板，不会创建第二个实例。若看到多个窗口，可能是旧版本残留，请完全退出托盘程序后重新打开。
    Windows 崩溃或强制结束后无法启动
    新版会自动检测并清理崩溃遗留的数据库进程记录（postmaster.pid），正常重启应用即可，不会删除数据。
    关闭主窗口后程序还在运行
    关闭主窗口只是隐藏窗口，灵枢与桌面宠物会继续在托盘运行。需要完全退出时，右键托盘图标选择退出。
    安装被安全软件拦截或提示缺少运行库
    安装包已内置 Microsoft C 运行库与数据库，无需预装。若被安全软件拦截，请对安装包或安装目录添加信任后重试，并从官网下载中心重新下载校验。
    聊天没有响应或提示模型错误
    本地聊天依赖 Ollama 或已配置的模型 API。请确认已安装并启动 Ollama（ollama serve），且“聊天设置”中选择了本机已安装的模型；语义记忆检索还需 ollama pull nomic-embed-text。
    联网搜索不可用
    联网搜索由独立权限开关控制，默认关闭。请在桌面端“权限”面板开启「L1 · 联网搜索」后重试。
    macOS 日历事件写入失败
    日历写入通过系统日历（EventKit）完成，仅支持 macOS 14+，且需要在“系统设置 → 隐私与安全性 → 日历”中允许灵枢访问。Windows 与网页版请使用日历导出（.ics 文件）。
    macOS 无法打开应用
    若提示“无法验证开发者”，请在“系统设置 → 隐私与安全性”中允许，或右键应用选择“打开”。macOS 版需要 Docker Desktop 提供本地数据库。
    设备列表出现多台“浏览器”设备
    首次登录或清理浏览器站点数据后会新建一条设备记录；同一浏览器之后的登录会复用设备。多余的旧记录可在“设备与会话”中撤销，不影响当前使用。
    如何备份本地数据
    Windows 版数据保存在 %APPDATA%\com.lingshu.desktop\embedded-postgresql。重装或换机前备份整个 com.lingshu.desktop 目录，恢复时放回相同位置。
    验证链接提示无效或已过期
    链接可能超过 24 小时、已经使用过，或复制时不完整。重新提交注册即可在旧记录过期后生成新验证链接。
    登录后又回到登录页
    会话可能已过期或被其他设备撤销。刷新页面并重新登录；若仍失败，确认浏览器未阻止该站点的本地存储。
    收不到验证邮件
    检查垃圾邮件和邮箱拼写。有效期内重复提交不会再次发送；请使用首次收到的邮件，或等待旧链接过期后重新注册。
    断网后还能使用吗
    桌面端本地核心功能可以继续使用；账户网页、设备管理、订阅查询和云同步需要联网。
    撤销设备会删除记忆吗
    不会。撤销只让该设备的云会话失效，不会删除桌面端本地数据，也不会删除账户。
    更换设备后为什么无法解密云端记忆
    先确认登录的是同一云账户，并逐字输入原设备使用的同步加密口令。云端不保存口令，无法代为找回；若口令遗失，只能继续使用仍可访问的本地数据与已有备份。
    Free 账户为什么能进入团队工作区
    受邀成员由所在团队授予工作区访问权，不要求个人购买 Team；可执行的操作仍由团队角色与记忆访问范围决定。创建新的工作区需要有效 Team 权益。
    网页目前不能做什么
    当前尚不提供忘记密码、修改密码和删除账户。记忆同步在桌面端完成，因为加密口令不会交给网页或云端。
